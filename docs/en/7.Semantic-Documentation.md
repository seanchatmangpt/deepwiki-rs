# Semantic Documentation

Litho can compile Rustdoc JSON into deterministic RDF instead of treating prose as the canonical documentation artifact.

## Boundary

The semantic documentation command is deliberately independent of the LLM documentation pipeline. Compiler-produced Rustdoc JSON is observation evidence; generated TriG is a projection of that evidence; neither grants execution authority.

```bash
cargo +nightly rustdoc -- --output-format json -Z unstable-options
cargo run -- semantic-docs \
  --rustdoc-json target/doc/<crate>.json \
  --repository owner/repo \
  --revision <exact-git-sha> \
  --output semantic-docs.trig
```

The output contains two named graphs:

- `urn:litho:graph:source:<revision>` — Rust items, fully-qualified paths when Rustdoc supplies them, visibility, source spans, and intra-doc references.
- `urn:litho:graph:documentation:<revision>` — Rustdoc Markdown as `sdoc:DocFragment` evidence linked to the item it documents.

A JSON receipt is written alongside the graph. It records the Rustdoc format version, exact repository/revision subject, counts, authority ceiling (`none`), standing, and falsifiers.

## Open Ontologies admission

Pass the Open Ontologies binary to make ontology validation a required boundary:

```bash
cargo run -- semantic-docs \
  --rustdoc-json target/doc/<crate>.json \
  --repository owner/repo \
  --revision <exact-git-sha> \
  --open-ontologies-bin /path/to/open-ontologies
```

Litho executes `open-ontologies validate <graph>`. A non-zero validator exit is fail-closed: the graph and receipt remain on disk as evidence, the receipt records the refusal, and the command exits with an error. Successful validation advances only this semantic-documentation subject; it does not imply runtime execution, publication, merge, or application authority.

## Design invariant

`RDF is documentation; prose is a projection.`

The current command does not replace the existing Markdown/C4 pipeline. It establishes the canonical machine-readable substrate required for later SPARQL-generated C4, Diátaxis, agent context, and conventional prose projections without making those projections sovereign.
